# Fotos de PREVIEW (tarjeta al compartir · Open Graph)

Fotos de ACCIÓN (en juego), más vistosas que la cara, que se ven al compartir
el enlace de un jugador en WhatsApp/Twitter/etc.

- Nombre del archivo: el id del jugador + `.jpg`  (ej. `pau-gasol.jpg`)
- Formato ideal: APAISADO, ~1200×630 px (proporción 1,91:1). Vale desde ~1000 px
  de ancho. Cuanto más nítida, mejor.
- La cara/acción, centrada, para que no se recorte.

Si un jugador NO tiene foto aquí, la tarjeta usa su foto de cara de img/players/.
